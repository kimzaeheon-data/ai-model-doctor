# 학습 정체 진단 테스트 사례 초안

## 목적

`training_plateau` 규칙을 구현하기 전에 입력 지표, 계산 방법, 예상 판정을 합의한다. 이 문서의 사례는 단위 테스트의 기준으로 사용한다.

## 계산 방식 제안

### 사전 조건

- 최소 학습 기록: 10 epoch
- 비교 지표: validation `mAP50-95`
- 구간 크기: `max(5, ceil(전체 epoch 수 × 0.20))`
- 비교 구간: 마지막 두 구간
- 각 구간에 `null`이 하나라도 있으면 우선 `insufficient_data`

### 개선 폭

```text
이전 최고점 = 이전 구간의 최대 mAP50-95
최근 최고점 = 최근 구간의 최대 mAP50-95
개선 폭 = 최근 최고점 - 이전 최고점
```

최대값끼리 비교하는 이유는 epoch별 일시적인 진동 때문에 시작값과 마지막 값만으로 정체를 판단하는 오류를 줄이기 위해서다.

### 판정

```text
개선 폭 < 0.005  → warning / 확인 필요
개선 폭 >= 0.005 → pass / 이상 징후 없음
판단 자료 부족   → insufficient_data / 판단 보류
```

경계값 `0.005`는 warning에 포함하지 않는다. 부동소수점 계산 시 내부적으로 충분한 정밀도를 유지하고 표시할 때만 반올림한다.

---

## 사례 1. 학습 기록 부족

### 입력

```text
전체 epoch: 8
mAP50-95: 0.20, 0.25, 0.29, 0.32, 0.35, 0.37, 0.38, 0.39
```

### 예상 결과

```text
title: 학습 정체
status: insufficient_data
status_label: 판단 보류
severity: none
confidence: 1.0
```

### 사용자 설명

> 학습 기록이 8 epoch로 최소 기준인 10 epoch보다 짧아 최근 성능 추세를 판단할 수 없습니다.

---

## 사례 2. 정상적으로 개선 중

### 입력

```text
전체 epoch: 10
이전 5 epoch: 0.35, 0.37, 0.38, 0.39, 0.40
최근 5 epoch: 0.405, 0.412, 0.419, 0.425, 0.43
```

### 계산

```text
이전 최고점: 0.400
최근 최고점: 0.430
개선 폭: 0.030
정체 기준: 0.005 미만
```

### 예상 결과

```text
title: 학습 정체
status: pass
status_label: 이상 징후 없음
severity: none
confidence: 0.9
```

### 사용자 설명

> 최근 구간의 mAP50-95 최고점이 이전 구간보다 0.030 상승하여 학습 정체 징후가 발견되지 않았습니다.

---

## 사례 3. 학습 정체

### 입력

```text
전체 epoch: 10
이전 5 epoch: 0.410, 0.415, 0.419, 0.420, 0.418
최근 5 epoch: 0.419, 0.421, 0.420, 0.423, 0.421
```

### 계산

```text
이전 최고점: 0.420
최근 최고점: 0.423
개선 폭: 0.003
정체 기준: 0.005 미만
```

### 예상 결과

```text
title: 학습 정체
status: warning
status_label: 확인 필요
severity: medium
confidence: 0.85
```

### 사용자 설명

> 최근 구간의 mAP50-95 최고점이 이전 구간보다 0.003 상승하는 데 그쳐 학습이 정체됐을 가능성이 있습니다.

### 원인 후보

- 현재 learning rate에서 추가 개선이 어려울 가능성
- 모델 용량 또는 입력 해상도의 한계 가능성
- 데이터 품질이나 다양성의 한계 가능성

### 권장 확인

- learning-rate 변화 확인
- train 및 validation loss 추세 확인
- 추가 학습보다 데이터 개선이 필요한지 검토

---

## 사례 4. 정확히 경계값만큼 개선

### 입력

```text
이전 최고점: 0.420
최근 최고점: 0.425
개선 폭: 0.005
```

### 예상 결과

```text
status: pass
status_label: 이상 징후 없음
```

### 이유

규칙이 `개선 폭 < 0.005`일 때만 warning이므로 정확히 0.005이면 통과한다.

---

## 사례 5. 최근 성능 하락

### 입력

```text
이전 5 epoch 최고점: 0.450
최근 5 epoch 최고점: 0.430
개선 폭: -0.020
```

### 예상 결과

```text
status: warning
status_label: 확인 필요
severity: medium
```

### 설명 원칙

학습 정체 규칙에서는 “개선되지 않았음”까지만 판정한다. 최고점 이후 하락의 크기와 원인은 향후 `post_peak_degradation` 규칙에서 별도로 다룬다.

---

## 사례 6. 최근 지표 누락

### 입력

```text
이전 5 epoch: 0.40, 0.41, 0.42, 0.42, 0.43
최근 5 epoch: 0.43, null, null, 0.431, null
```

### 예상 결과

```text
status: insufficient_data
status_label: 판단 보류
severity: none
confidence: 1.0
```

### 사용자 설명

> 최근 비교 구간에 mAP50-95 누락값이 있어 학습 정체 여부를 안정적으로 판단할 수 없습니다.

## 구현 전 승인할 기준

1. 시작값·마지막 값이 아니라 연속된 두 구간의 최대값을 비교한다.
2. 개선 폭이 `0.005` 미만일 때만 warning으로 판단한다.
3. 최근 두 비교 구간 중 하나라도 지표가 누락되면 판단을 보류한다.
4. 최근 성능 하락은 이 규칙에서 warning으로 표시하되 상세 진단은 별도 규칙에 맡긴다.
5. 첫 버전의 warning 심각도는 `medium`으로 고정한다.
